# Moviq (demo)

Watch free public-domain films, log and review what you watch, and get recommendations from a hybrid
recommender. Includes a Spoiler Shield that blurs spoiler sentences, a 60-second Decide mode and
group picks.

Click **Try it as a guest** on the sign-in page to look around. This is a portfolio demo: the database
resets whenever the Space restarts.

Source: https://github.com/Boovesh985/Moviq

Film data, artwork and reviews come from TMDB. This product uses the TMDB API but is not endorsed or
certified by TMDB. Ratings from the MovieLens dataset (GroupLens, University of Minnesota), used under
its non-commercial licence.
